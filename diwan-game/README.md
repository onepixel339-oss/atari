# الديوان — لعبة أسئلة المكتب 🏢

لعبة ويب كاملة (HTML/CSS/JavaScript فانيلا) — **مفيش تسطيب ولا أدوات ولا برمجة**. الملفات دي بتشتغل زي ما هي على أي استضافة.

---

## 1) تشغيلها على جهازك (اختياري)

دبل كليك على `index.html` يفتحها المتصفح عادي.

الأفضل (بصوت وسلاسة أكمل): افتح الترمينال في المجلد ده واكتب:

```
python3 -m http.server 8000
```

وبعدين افتح: `http://localhost:8000`

---

## 2) الرفع على GitHub (من المتصفح، من غير أي برامج)

1. اعمل حساب على `github.com` وادخل عليه.
2. اضغط زر **+** فوق واختار **New repository**.
3. اسم المستودع: `diwan-game` — سيبه **Public** — اضغط **Create repository**.
4. في الصفحة اللي هتظهر، اضغط رابط **uploading an existing file**.
5. افتح مجلد `diwan-game` ده و**اسحب كل اللي جواه** (index.html و styles.css ومجلدات js و data و img) وارميهم في صفحة الرفع.
   - ⚠️ **أهم حاجة**: ملف `index.html` لازم يبقى في **جذر** المستودع (مش جوه فولدر زيادة).
6. اضغط **Commit changes** واستنى الرفع يخلص.

---

## 3) النشر على Vercel (مجاني)

1. اعمل حساب على `vercel.com` **بحساب GitHub نفسه** (زر Continue with GitHub).
2. اضغط **Add New → Project** واختار مستودع `diwan-game`.
3. في إعدادات الاستيراد:
   - **Framework Preset**: اختار `Other`
   - **Build Command**: سيبه فاضي
   - **Output Directory**: سيبه فاضي
4. اضغط **Deploy**.
5. بعد دقيقة هتاخد رابط دايم زي: `https://diwan-game.vercel.app` — ده اللي تبعته ل أصحابك.

---

## 4) تحديث اللعبة بعدين (أهم جزء!)

التعديل كله بيتم في ملف واحد: **`data/questions.js`**

- تقدر تعدله **من موقع GitHub نفسه**: افتح الملف في المستودع → اضغط أيقونة القلم ✏️ → عدّل → Commit.
- أول ما تعدّل، **Vercel بينشر النسخة الجديدة لوحده** في دقيقة من غير أي خطوة زيادة.

### شكل السؤال جوه الملف:

```js
{ cat:'culture', catLabel:'ثقافة عامة', levelLabel:'سهل', time:15,
  text:'نص السؤال هنا؟',
  options:['الاختيار الأول','التاني','التالت','الرابع'],
  correct:0,              // رقم الإجابة الصح: 0=الأول، 1=التاني، 2=التالت، 3=الرابع
  hint:'تلميح يظهر بعد استخدام الاستئناف',
  explanation:'شرح الإجابة اللي هيظهر في المراجعة' }
```

- `MAIN_QUESTIONS` = الأسئلة العادية (30 سؤال — `time:15` ثانية)
- `GENIUS_QUESTIONS` = أسئلة جولة المخاطرة (7 أسئلة — `time:90` ثانية و `cat:'genius'`)

### ⚡ حاجة مهمة بتحصل لوحدها:

أول مرة حد يفتح اللعبة **بعد تغيير ملف الأسئلة**، اللعبة بتوصف لوحة الشرف والحفظ القديم وتقول **"🔔 جولة جديدة بدأت"** — ده مقصود، عشان نقاط الجولة القديمة ما تختلطش بالجديدة (نظام النقاط اتغير أو الأسئلة اتغيرت).

### نظام النقاط (للمراجعة):

| الحالة | النقاط |
|---|---|
| إجابة صح في التلت الأول من الوقت | **+15** |
| في التلت التاني | **+10** |
| في التلت الأخير | **+5** |
| إجابة غلط (عادي) | **0** |
| مخاطرة: صح | **+20** |
| مخاطرة: غلط | **−12** |
| الشاي | −15 |
| أقصى مجموع في الجولة | **590** |

## 5) بنية الملفات

| الملف / المجلد | دوره |
|---|---|
| `index.html` | هيكل اللعبة وكل الشاشات |
| `styles.css` | التصميم كامل (ستايل جيبلي مرسوم) |
| `js/game.js` | منطق اللعبة: النقاط، المؤقت، الحفظ، لوحة الشرف، الشهادة |
| `js/ambience.js` | الأصوات (أجواء المكتب) + حركة المروحة والساعة والمشهد |
| `data/questions.js` | **الأسئلة** — الملف الوحيد اللي هتعدله |
| `img/` | الرسومات (المكتب، الملفات، الورق) |

---

## ملاحظات سريعة

- لوحة الشرف والحفظ بيتحفظوا في **متصفح اللاعب نفسه** (localStorage) — يعني كل جهاز ليه لوحده، مفيش سيرفر مركزي.
- اللعبة بتحترم إعداد "تقليل الحركة" في الموبايل، وشاشة كاملة بـ iframe أو مباشرة.
- كل الأصوات بتشتغل بعد أول لمسة في الصفحة (سياسة المتصفحات) وفيها زر كتم.
